# 自检机制

解决两个问题：**内容该上线了却没上线**，以及**海报张冠李戴**。
两者都由 `tools/self-check.sh` 统一自检，发现不对就自动修，修完再复核一遍。

```bash
npm run self:check                 # 自检 + 自动修复
npm run self:check -- --check-only # 只自检，不改动任何东西
npm run sync:check                 # 只查同步时效（有未及时同步时退出码 1）
```

## 一、同步时效自检

`tools/check-sync.mjs` 沿着整条链路逐段核对，明确指出卡在哪一段：

```text
WorkBuddy 源目录 → source-html/ → movies.json → 本地提交 → 远程仓库 → 线上站点
```

| 检查项 | 级别 | 含义 | 修复动作 |
| --- | --- | --- | --- |
| `source_dir_missing` | 提示 | WorkBuddy 输出目录不存在 | 设置 `DAILY_SRC` |
| `source_not_copied` | 未同步 | 源目录有新页面没复制进 `source-html/` | `tools/daily-sync.sh` |
| `not_parsed` | 未同步 | 页面没解析进 `movies.json` | `tools/daily-sync.sh` |
| `parsed_orphan` | 提示 | `movies.json` 有记录但找不到对应页面 | 检查是否误删 |
| `poster_missing` | 未同步 | 新片还没抓到海报 | `npm run data:gallery` |
| `uncommitted` | 未同步 | 内容改动没提交 | `tools/daily-sync.sh` |
| `unpushed` | 未同步 | 提交了但没推到远程 | `git push origin HEAD` |
| `behind_remote` | 提示 | 本地落后于远程 | `git pull --rebase` |
| `remote_unreachable` | 提示 | 读不到远程状态 | 检查网络与凭据 |
| `deploy_pending` | 提示 | 刚推送，线上还在部署 | 等待 Actions |
| `not_live` | 未同步 | 推送很久了线上仍没出现 | 检查 Actions 构建 |
| `site_unreachable` | 提示 | 线上站点打不开，跳过核对 | 设置 `SITE_URL` |

宽限期（避免刚生成就被误判）：

| 环境变量 | 默认 | 含义 |
| --- | --- | --- |
| `SYNC_GRACE_MINUTES` | 30 | 源文件生成多久后，才要求它已经同步 |
| `DEPLOY_GRACE_MINUTES` | 10 | 推送后多久内，允许线上还没更新 |
| `DAILY_SRC` | WorkBuddy 输出目录 | 源 HTML 目录 |
| `SITE_URL` | 由 git remote 推导 | 线上地址 |

## 二、海报自检

复用已有的巡检与纠错能力（详见 [海报自检机制.md](海报自检机制.md)）：

- 自检：`tools/check-posters.mjs` 检查竖版比例、分辨率、体积、图源可信度、
  片名与图是否对得上（身份证据分 strong / medium / weak 三档，并识别
  「同名不同片」「新片报道」「片单合集帖」这类反向疑点）、是否两部片共用一张图等
- 自动修复：`tools/fix-posters.mjs` 重新抓取可信图源、就地替换并复检；
  候选必须证据充分且不得与现用图相同
- 人工核对：`npm run poster:review` 生成 `output/poster-review.html`，
  把机器不敢打包票的图挑成一页；核对后用 `npm run poster:set` 替换或登记

自检脚本默认在「有新内容」或「距上次巡检超过 24 小时」时才跑海报这一环，
避免每小时都去访问一遍图源。用 `--posters=always` 可以强制每次都跑。

## 三、产出

| 文件 | 内容 |
| --- | --- |
| `output/self-check.md` | 本次自检结论（同步 + 海报 + 修复动作） |
| `output/self-check.json` | 同上，机器可读 |
| `output/sync-audit.json` | 同步链路逐段核对结果 |
| `output/poster-audit.md` | 海报巡检明细 |
| `output/poster-fix-log.json` | 海报替换记录 |
| `output/poster-review.html` | 海报人工核对页（机器证据不足的那些） |

退出码：`0` = 一切正常（含已自动修好）；`1` = 仍有未解决项。
定时任务的日志在 `/tmp/classicmovie-selfcheck.log`。
